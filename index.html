03
CORE ALGORITHMS

Explainable calculations first

01

Skill normalization

Trim and standardize names, then map reviewed synonyms to one stable skill ID. Embeddings may help suggest matches later, but a human-approved mapping is still needed.

alias → canonical skill_id
02

Gap detection & priority

For each required skill, compare target level r with assessed level u, then weight the gap by role importance w.

gapᵢ = max(0, rᵢ − uᵢ)priorityᵢ = wᵢ × gapᵢ / 4
03

Readiness indicator

Summarize weighted skill coverage, capped at the expected level. It is a study indicator, not a hiring score or employment probability.

100 × Σ[wᵢ × min(uᵢ/rᵢ, 1)]÷ Σwᵢ
04

Roadmap scheduling

Sort gaps by priority, select the highest ones and divide available weekly hours proportionally. A later graph-based version can respect prerequisites.

O(S log S) sort
O(V + E) graph order¹
05

Baseline assessment

Score the tagged sample questions with a transparent answer key and explanation. This small quiz is not an adaptive or validated psychometric test.

score = correct / attempted
S = skills / gaps · V = prerequisite nodes · E = prerequisite links. Gap scan O(S) time; sorting O(S log S); Map / Set lookup O(1) average; topological order O(V + E) only after dependency validation. Space depends on the records stored.
04
AI / ML ROADMAP

What is live now vs. planned

LIVE IN THIS DEMO

Rules-based gap ranking

Skill targets, assessment values and weekly time produce a repeatable plan. Same inputs give the same result.

NEXT · AFTER DATA REVIEW

Adaptive quiz

Consider a calibrated Rasch / item-response model only after building enough reviewed questions per skill and collecting pilot responses. It estimates question difficulty b and learner ability θ; it is not meaningful with an unvalidated tiny quiz. Example one-parameter model: P(correct) = 1 / (1 + e^(b − θ)).

PLANNED · SECURE BACKEND

Grounded AI Coach

Retrieval-augmented generation can retrieve approved role facts and learning resources, then explain them with visible citations. Keep model keys on the server and evaluate answers for unsupported claims.

OPTIONAL · VALIDATE FIRST

Skill-name matching

Start with aliases and expert-reviewed mappings. Embedding similarity can suggest related wording: cos(A,B) = (A · B) / (|A| |B|). Similarity alone must not declare a skill gap or role match.

!

No model has been trained or connected in this website. For the review demo, the “Coach” uses simple rules. AI guidance should support learning only—never automated selection, rejection or a job guarantee.

PUBLIC WEBSITE & PRIVACY

What deployment means

GitHub Pages capacity

Pages publishes static files. GitHub currently sets a soft 100 GB monthly bandwidth limit and a soft limit of 10 builds per hour. Those limits are not a fixed visitor count; page size, repeat visits, caching and traffic shape usage.

Official usage limits ↗

Browser-local profiles

Each browser saves its own demo data in local storage. It does not sync across devices and should not be used for passwords or sensitive personal information.

For real accounts

Add a backend, secure authentication, database access controls, privacy notice, backups, rate limits and abuse monitoring before accepting real student data.
